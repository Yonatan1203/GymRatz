Color Usage Improvements

Status Colors

Completed workouts → teal tint. Scheduled → muted/border. Missed → orange (keep existing). Active/in-progress → coral tint. Consistent across calendar, workout cards, program badges.

Icon Backgrounds

All icon containers use the same pattern: 10% opacity tint of the icon's semantic color + matching border. Teal for informational, coral for action/energy, destructive for errors.

Text Hierarchy

Enforce 3 levels only: foreground (primary text), mutedForeground (secondary/supporting), mutedForeground at 60% opacity (tertiary/captions). No more random opacity values.

Interactive States

Pressed: ScaleTap (0.97) + slight opacity reduction (0.9). Disabled: 40% opacity, no tap response. Focused inputs: teal border (existing, keep). Selected option: teal fill at 10% + teal border.

Small Details That Add Up

•
Dividers: Replace hard 1px dividers with 8px vertical spacing where possible. Where dividers are needed, use muted color at 30% opacity — barely there.
•
Scroll behavior: Header tint fades to full background on scroll. Subtle — makes content feel like it's sliding under the header.
•
Number animations: Stats and counters count up from 0 on first appearance (200ms). Workout volume, streak count, PR values. Creates a sense of achievement.
•
Theme toggle: Keep sun/moon icon swap but add a 200ms rotation transition. Small delight.
•
Safe areas & bottom padding: Audit all screens for consistent bottom padding (account for bottom nav height + safe area). No content cut off.
