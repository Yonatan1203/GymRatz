The Rules
Header Zone
  • Subtle tint bg + thin bottom border
  • Title (h1) left-aligned, always
  • Optional action button top-right
  • Optional subtitle below title
  • Safe area padding top: 48r
Content Zone
  • Screen padding: 24r horizontal
  • Section gap: 24r between sections
  • Each section starts with SectionHeader
  • Cards use 14r border radius (xl)
  • Content animates in with StaggeredList
Spacing Rhythm
  • Between sections: 24r (sectionGap)
  • Section header → content: 12r (itemGap)
  • Between cards in a list: 12r
  • Inside cards: 16r (cardPadding)
  • Stats grid gap: 8r
Interaction Pattern
  • All tappable cards wrap in ScaleTap
  • Chevron (›) on navigable items
  • Haptic feedback on all taps
