GymRatz UI/UX Polish — Priority Map (Updated)

Design system cohesion added as Tier 1 foundation

🔴 Tier 1 — High Impact (Most work needed)

★ Design System Cohesion Foundation

Currently: Each screen feels like it was built independently. Card styles, header treatments, content layouts, and interaction patterns vary from screen to screen. No shared visual rhythm.
Plan: Define and enforce a unified screen template — consistent header → content → action flow, standardized card variants, shared section patterns, uniform interaction feedback. Every screen should feel like it belongs to the same family.

A — Transitions & Animations Critical

Currently: No page transitions, no micro-interactions, static state changes. Only 2 animations exist (pulsing dot + toggle).
Plan: Add page transitions, list item staggers, state change animations, button feedback, scroll-driven effects. Make the app feel alive.

D — Onboarding Flow Critical

Currently: 14 screens with basic layout, no transition between steps, progress bar is functional but not delightful.
Plan: Smooth slide transitions between steps, animated progress bar, staggered content entry, polished selection cards, cohesive visual story.

🟡 Tier 2 — Medium Impact

B — Cards & Containers Medium

Create card variants with distinct visual identities while keeping the same base. Workout cards feel different from stat cards feel different from program cards.

F — Spacing & Hierarchy Medium

Audit every screen for consistent spacing rhythm, enforce section gaps, standardize header-to-content flow.

🟢 Tier 3 — Polish & Refinement

E — Empty/Loading States · G — Color Usage · C — Bottom Nav

Skeleton loaders, animated empty states, friendlier errors, better status color differentiation, nav active indicator animation.

Execution order: Design System first → then Animations → then Onboarding → then Tier 2 → Tier 3

Design System is the foundation — animations and onboarding build on top of it. Does this look right?
