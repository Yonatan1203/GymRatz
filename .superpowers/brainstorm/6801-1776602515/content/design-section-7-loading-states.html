Design Section 7 — Loading, Empty & Error States

Every state should feel intentional, not like a placeholder

Loading States — Skeleton Loaders Replace Spinners

Current — Generic Spinner
Loading workouts...
Same spinner everywhere.
No hint of what's coming.
Feels slow even when it's fast.
Proposed — Skeleton Shimmer
Shimmer animation on skeleton bars.
Matches the card layout that will appear.
Feels instant.
Rule: Skeleton loaders mirror the shape of the content they replace. Workout screen shows workout card skeletons. Programs screen shows program card skeletons. Stats show stat card skeletons. A subtle shimmer animation (left→right gradient sweep, 1.5s loop) keeps it alive.

📋

Icon fades in (200ms) → title slides up (150ms) →
subtitle fades (100ms) → button slides up (100ms)
Improvements: Larger icon container (64px, rounded square). More descriptive copy that explains the value. CTA uses coral styling for action emphasis. Staggered entry animation. Consistent across all empty states.

Error States — Helpful, Not Scary

Proposed Error State
⚠️
Couldn't load workouts
Check your connection and try again
Try Again
Rules: Destructive-tinted icon container. Specific error message (not generic "Something went wrong"). Actionable retry button in teal (not coral — errors shouldn't feel exciting). Same staggered animation as empty states.
